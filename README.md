## 🚀 Featured project

### [graded-env-reference](https://github.com/omair25-ozi/graded-env-reference)

A reference **agent-evaluation environment**: exact programmatic grading, an enforced memory ceiling, privilege-dropped execution and a 12-mutant must-fail matrix.

```text
$ python3 scripts/verify.py

case                      verdict  mode     peak RSS
----------------------------------------------------
reference                 PASS     -        13.5 MiB
m01_accumulate_all        FAIL     memory   26.6 MiB
m06_float_serialization   FAIL     answer   13.3 MiB
m08_print_verdict         FAIL     silent   11.9 MiB
m10_fork_spread           FAIL     fanout   24.1 MiB
...

matrix clean: reference passes, all 12 mutants fail,
each for the reason it was written to fail for.
```

- 🎲 The task and the expected answer are both derived from a seed, so there is nothing on disk to copy
- 🔒 The candidate writes its answer to a file it cannot read back, and printed "PASS" lines are never trusted
- 📏 A 32 MiB address-space ceiling plus a process cap; found and closed a fork-sharding bypass of the per-process limit
- ✅ Reference solution checked against a brute-force oracle on 3,005 instances
